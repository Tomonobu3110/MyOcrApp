# 動作シーケンス概略

## パターン1: カメラ撮影 → OCR → 自動登録

```
[ユーザー]                [MainActivity]              [ML Kit]         [Lambda]            [ConfirmActivity]        [外部CGI]
    |--- シャッターを押す --->|                           |                |                      |                      |
    |                      |--- 撮影 -------------------->|                |                      |                      |
    |                      |<-- 画像ファイル保存完了 ------|                |                      |                      |
    |                      |--- OCR実行(processImage) --->|                |                      |                      |
    |                      |<-- 認識テキスト --------------|                |                      |                      |
    |<-- OCR結果ダイアログ --|                           |                |                      |                      |
    |--- OK ---------------->|                           |                |                      |                      |
    |                      |--- OCRテキストをPOST ------------------------>|                      |                      |
    |                      |<-- 店名・日付・金額・品目(JSON) ---------------|                      |                      |
    |                      |--- response_jsonを渡して起動 ----------------------------------------->|                      |
    |<----------------------------------------------- 確認フォーム表示 ----------------------------|                      |
    |--- 内容を修正・確認 --------------------------------------------------------------------------->|                      |
    |--- 「個人」「家計」「立替」いずれかの送信ボタンを押す --------------------------------------------->|                      |
    |                                                                                               |--- multipart POST -->|
    |                                                                                               |<-- 200 OK ------------|
    |<---------------------------------------------- 「送信しました」トースト表示 --------------------|                      |
```

主な登場クラス: `MainActivity`（カメラ・OCR・Lambda呼び出し） → `lambda_function.py`（解析） → `ConfirmActivity`（確認・編集） → `FormSubmitter`（外部CGIへの送信）

## パターン2: 他アプリから画像共有（OCR以降は パターン1 と同じ）

```
[他のアプリ（ギャラリー等）]        [MainActivity]
         |--- 「共有」→ このアプリを選択 --->|
         |                                |--- ACTION_SEND インテントを受信
         |                                |--- Uri を一時ファイルに変換 (uriToFile)
         |                                |--- processImage() 実行
                                           （以降はパターン1の OCR 実行以降と同じ）
```

アプリを起動していない状態でも、画像を共有した瞬間に`MainActivity`が起動しOCRが走る。

## パターン3: クイック登録（OCRを使わない）

```
[ユーザー]                [MainActivity]                       [ConfirmActivity]        [外部CGI]
    |--- 「クイック」ボタンを押す --->|                                    |                      |
    |                              |--- SharedPreferences の          |                      |
    |                              |    QuickShop/QuickPayment/       |                      |
    |                              |    QuickItems + 今日の日付から    |                      |
    |                              |    JSONを組み立て                 |                      |
    |                              |--- response_jsonを渡して起動 ------->|                      |
    |<------------------------------------------- 確認フォーム表示 ------|                      |
    |--- 内容を確認・送信ボタン ------------------------------------------>|                      |
                                                                        |--- multipart POST -->|
```

Lambda呼び出しを経由しないため、ネットワークが遅い・不安定な場面でも、よく使う店の登録を素早く行える。

## 補足: 設定の読み書き

`SettingActivity`は上記のどのシーケンスにも直接登場しないが、各シーケンス中で参照される`LambdaUrl` / `CgiUrl` / `Cgi2Url` / `Account` / `QuickShop` / `QuickPayment` / `QuickItems`は、事前にこの画面で入力・保存しておく必要がある（`SharedPreferences`の`AppSettings`に保存）。未設定の場合、各シーケンスの途中でトーストによるエラー表示（「URLが設定されていません」等）が出て処理が止まる。
